[English](#english) | [中文](#中文)

# **English**

## Overview

Turn the entire Overworld into an eternal winter. Select the **Winter Falls** world type when creating a new world to enable all winter mechanics.

## World Type

When creating a new save, choose **Winter Falls** from the world type dropdown.
- Selected → All winter effects enabled
- Not selected → Vanilla gameplay, no dimension modification

## Features

- Eternal Blizzard — It always snows in the Overworld, vanilla weather cycle disabled
- Ground Snow Cover — Snow layers are placed everywhere upon entering the world, thickens naturally over time
- Water Freezing — All exposed water surfaces freeze into ice automatically
- Winter Fog — Thick winter fog during nighttime and snowy weather
- Custom Snow Rendering — Replaces vanilla snow with denser, more atmospheric snow particles
- Pale Winter Sky — Removes sunrise and sunset colors for a muted winter sky

## Limitations

- Only affects the Overworld. The Nether, End, and modded dimensions are untouched
- Snow does not accumulate on ice

## Configuration

Accessible via Mod Menu:
- Snow accumulation check interval and probability
- Maximum snow layer thickness
- Toggle vanilla weather cycle

# **中文**

## 简介

将整个主世界变成永恒的寒冬。创建世界时选择 **"寒冬降临"** 世界类型即可启用所有冬天机制。

## 世界类型

创建新存档时，在世界类型下拉框选择 **寒冬降临（Winter Falls）**。
- 选了 → 启用全部冬天效果
- 不选 → 完全原版，不干预任何维度

## 特性

- 永恒暴风雪 — 主世界永远下雪，原版天气循环被禁用
- 地表积雪 — 进入世界即铺满雪层，雪会自然增厚
- 水面结冰 — 所有露天水面自动冻结成冰
- 冬日浓雾 — 夜晚和雪天有浓浓的冬日雾气
- 自定义雪花 — 替换原版雪花渲染，更密集更有冬天感
- 灰白天空 — 去除日出日落色彩，天空呈冬日灰白

## 限制

- 仅影响主世界，下界 / 末地 / 其他模组维度不会下雪或积雪
- 冰块上不会积雪

## 配置

模组菜单里有配置界面，可以调节：
- 积雪检查间隔与概率
- 最大雪层厚度
- 是否禁用原版天气循环
