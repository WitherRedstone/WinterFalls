# **中文**

## 简介

将整个主世界变成永恒的寒冬。创建世界时选择 **"寒冬降临"** 世界类型即可启用所有冬天机制。

## 特性

- 主世界永远下雪，原版天气循环被禁用
- 进入世界即铺满雪层，雪会自然增厚
- 所有露天水面自动冻结成冰
- 夜晚和雪天有浓浓的冬日雾气
- 去除日出日落色彩，天空呈冬日灰白
- 雪傀儡不会再被天气和温度影响

## 配置

模组菜单里有配置界面，可以调节：
- 积雪检查间隔与概率
- 最大雪层厚度
- 是否禁用原版天气循环
